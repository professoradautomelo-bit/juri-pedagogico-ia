## Como ativar o GitHub Pages

1. Acesse Settings > Pages.
2. Em Source, escolha Deploy from a branch.
3. Em Branch, selecione main/principal e /root ou /(raiz).
4. Clique em Save/Salvar.
5. Aguarde alguns minutos.
6. Acesse os links públicos acima.

## Observação

As respostas ficam salvas no navegador usado durante a atividade. Ao final, use Exportar CSV.
