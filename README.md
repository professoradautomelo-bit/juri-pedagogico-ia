# Júri Pedagógico sobre Inteligência Artificial na Escola

Site pedagógico para registro dos argumentos do Júri Popular sobre o uso de Inteligência Artificial em atividades escolares.

## Link público esperado

https://professoradautomelo-bit.github.io/juri-pedagogico-ia/

## Como ativar o GitHub Pages

1. Acesse Settings > Pages.
2. Em Source, escolha Deploy from a branch.
3. Em Branch, selecione main e /root.
4. Salve e aguarde alguns minutos.
5. Acesse o link público.

## Observação

As respostas ficam salvas no navegador usado durante a atividade. Ao final, use Exportar CSV.
